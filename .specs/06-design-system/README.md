# Sistema de Diseño y Ergonomía UI/UX (Dominio 06 - Impeccable Style)
**Estado:** `PLANIFICADO (Hito 1 - Guía y Tokens)`  
**Arquitecto Responsable:** `@impeccable-designer`

## Alcance
- Tokens de diseño industrial (Dark Mode por defecto, contraste elevado, paletas de semáforo metrológico).
- Tipografía técnica monoespaciada para valores de presión, temperatura, densidad, masa y factores $Z$.
- Componentes UI ergonómicos para estación: Inputs con debounce, visor SVG de racks (11/12 cilindros), curvas isocóricas.
- Filosofía Impeccable: Simplicidad, sobriedad, consistencia absoluta y cero distracciones para el operador de campo.
